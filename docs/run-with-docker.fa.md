# راهنمای اجرای برنامه روی سیستم شما

این راهنما قدم‌به‌قدم توضیح می‌دهد چطور برنامه را روی کامپیوتر خودتان اجرا کنید. لازم نیست برنامه‌نویسی بلد باشید؛ فقط مراحل را به ترتیب انجام دهید.

---

## قدم ۱: نصب Docker Desktop (فقط یک بار)

Docker برنامه‌ای است که همه‌چیزِ موردنیاز (دیتابیس و خود برنامه) را خودش آماده و اجرا می‌کند.

1. به این آدرس بروید: https://www.docker.com/products/docker-desktop/
2. نسخه‌ی مخصوص سیستم‌عامل خودتان (Windows یا Mac) را دانلود و نصب کنید.
3. اگر در حین نصب خواست سیستم را ری‌استارت کنید، این کار را بکنید.
4. بعد از نصب، برنامه‌ی **Docker Desktop** را باز کنید و صبر کنید تا کاملاً بالا بیاید (پایین صفحه‌اش سبز شود یا بنویسد **Engine running**).

> ⚠️ هر بار که می‌خواهید برنامه را اجرا کنید، **Docker Desktop باید باز باشد**.

---

## قدم ۲: دانلود پروژه و باز کردن ترمینال داخل آن

### الف) دانلود پروژه از GitHub

این پروژه خصوصی است، پس اول باید دسترسی داشته باشید:

1. اگر حساب GitHub ندارید، در https://github.com یک حساب بسازید و نام کاربری‌تان را برای من بفرستید.
2. یک ایمیل دعوت از GitHub برایتان می‌آید. داخل آن روی **View invitation** و بعد **Accept invitation** بزنید.

بعد از قبول دعوت:

1. با حساب GitHub خودتان وارد شوید و به این آدرس بروید: https://github.com/SinaTZ0/zurvan
2. روی دکمه‌ی سبز **Code** بزنید و بعد **Download ZIP** را انتخاب کنید.
3. فایل zip دانلودشده را Extract کنید (روی آن کلیک راست کنید و **Extract All** را بزنید).

پوشه‌ای که بعد از Extract ساخته می‌شود، **پوشه‌ی پروژه** است. داخل این پوشه فایلی به اسم `compose.yaml` وجود دارد. اگر آن را نمی‌بینید، احتمالاً یک پوشه‌ی دیگر داخل آن هست؛ واردش شوید.

### ب) باز کردن ترمینال داخل پوشه‌ی پروژه

**در ویندوز:**

1. پوشه‌ی پروژه را در File Explorer باز کنید.
2. روی نوار آدرس بالای پنجره کلیک کنید، متن آن را پاک کنید، بنویسید `cmd` و Enter بزنید.
3. یک پنجره‌ی سیاه (ترمینال) باز می‌شود که مستقیماً داخل همین پوشه است.

**در مک:**

1. روی پوشه‌ی پروژه در Finder کلیک راست کنید.
2. گزینه‌ی **New Terminal at Folder** را بزنید.

## قدم ۳: اجرای برنامه

این دستور را در ترمینال تایپ (یا کپی) کنید و Enter بزنید:

```bash
docker compose up --build
```

- **بار اول چند دقیقه طول می‌کشد** چون باید چیزهایی را دانلود کند. صبور باشید.
- متن‌های زیادی در ترمینال رد می‌شود؛ طبیعی است و نگران نباشید.
- وقتی دیگر متن جدیدی اضافه نشد و چیزی شبیه این دیدید، برنامه آماده است:

```text
app-1  | [react-router-serve] http://localhost:3000
```

> ⚠️ **این پنجره‌ی ترمینال را نبندید.** تا وقتی باز است، برنامه در حال اجراست.

---

## قدم ۴: باز کردن برنامه در مرورگر

مرورگر (Chrome، Firefox یا Edge) را باز کنید و این آدرس را بزنید:

**http://localhost:3000**

> ⚠️ آدرس را **دقیقاً همین‌طور** بنویسید. اگر به‌جای `localhost` چیز دیگری (مثل `127.0.0.1` یا آی‌پی سیستم) بنویسید، ثبت‌نام و ورود کار نمی‌کند.

حالا می‌توانید وارد شوید و برنامه را تست کنید. 🎉

### ورود با حساب‌های نمایشی

این نسخه نمایشی است و پیامک واقعی نمی‌فرستد. برای ورود، شماره‌ی موبایل را بزنید و کد **12345** را وارد کنید. هر شماره‌ای که بزنید، اگر اولین بار باشد، یک حساب مشتری تازه ساخته می‌شود.

برای دیدن سایت از چشم نقش‌های مختلف، این شماره‌ها از قبل ساخته شده‌اند و در صفحه‌ی ورود هم فهرست شده‌اند:

| شماره         | نقش                 |
| ------------- | ------------------- |
| `09120000001` | مدیر و مربی ارشد    |
| `09120000002` | دستیار مربی         |
| `09120000003` | همکار (پت‌شاپ)      |
| `09120000004` | مشتری با دو سگ      |
| `09120000005` | مشتری تازه، بدون سگ |

## خاموش کردن برنامه

- در همان پنجره‌ی ترمینال، کلیدهای **Ctrl + C** را با هم بزنید.
- اطلاعاتی که ساخته‌اید (حساب کاربری و …) پاک **نمی‌شود** و دفعه‌ی بعد سر جایش است.

## اجرای دوباره در روزهای بعد

1. Docker Desktop را باز کنید.
2. مثل قدم ۲ ترمینال را داخل پوشه‌ی پروژه باز کنید.
3. همان دستور قدم ۳ را بزنید. دفعه‌های بعد خیلی سریع‌تر بالا می‌آید.

## وقتی نسخه‌ی جدید برنامه را گرفتید

1. برنامه را خاموش کنید (Ctrl + C).
2. مثل قدم ۲ (الف) دوباره ZIP را دانلود و Extract کنید و پوشه‌ی جدید را جایگزین پوشه‌ی قبلی کنید.
3. ترمینال را داخل پوشه‌ی جدید باز کنید و همان دستور قدم ۳ را بزنید. عبارت `--build` باعث می‌شود نسخه‌ی جدید ساخته شود.

اطلاعات شما (حساب کاربری و …) با این کار پاک نمی‌شود.

## مشکلات رایج

| مشکل                                                             | راه‌حل                                                                                                                                               |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| پیام `docker: command not found` یا `'docker' is not recognized` | Docker Desktop نصب نیست یا باز نیست. قدم ۱ را انجام دهید و Docker Desktop را باز کنید، بعد ترمینال را ببندید و دوباره باز کنید.                      |
| پیامی شامل `Cannot connect to the Docker daemon`                 | Docker Desktop باز نیست یا هنوز کامل بالا نیامده. بازش کنید، کمی صبر کنید و دوباره دستور را بزنید.                                                   |
| پیامی شامل `port is already allocated` یا `3000`                 | برنامه‌ی دیگری از پورت 3000 استفاده می‌کند. آن برنامه را ببندید (یا سیستم را ری‌استارت کنید) و دوباره امتحان کنید.                                   |
| پیام `no configuration file provided`                            | ترمینال داخل پوشه‌ی پروژه باز نشده. قدم ۲ را دوباره انجام دهید.                                                                                      |
| صفحه در مرورگر باز نمی‌شود                                       | مطمئن شوید ترمینال هنوز باز است و متن `http://localhost:3000` را در آن دیده‌اید. چند ثانیه صبر کنید و صفحه را رفرش کنید.                             |
| ثبت‌نام یا ورود خطا می‌دهد                                       | آدرس را دقیقاً `http://localhost:3000` بنویسید (قدم ۴).                                                                                              |
| می‌خواهید همه‌چیز از اول و تمیز شروع شود                         | برنامه را خاموش کنید، دستور `docker compose down -v` را بزنید و بعد دوباره قدم ۳ را اجرا کنید. ⚠️ این کار همه‌ی اطلاعات (حساب‌ها و …) را پاک می‌کند. |

اگر باز هم مشکل داشتید، از کل متن ترمینال اسکرین‌شات بگیرید و بفرستید. 🙂
