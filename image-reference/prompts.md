# Home Page Image Prompts

Paste each prompt into ChatGPT as is. Save every result as PNG in `image-reference/generated/` under the file name given, and I'll slice the sheets, grade and compress them, and put them in `public/photo/`.

**Every prompt already ends with the shared style**, so all photos match: dark, cinematic, black background, warm amber light, no text.

If ChatGPT draws the grid unevenly (cells of different sizes, thick borders), ask it once: "Redraw it with exactly equal cells and thin black gutters." It doesn't have to be perfect: I cut each cell by hand if needed.

Why 4 per sheet and not 6: a sheet is at most 1536×1024. With 6 cells each photo is about 500px wide, which looks soft on a phone or a retina screen. With 4 cells each is about 760px, enough for the course cards. The doodles are small, so they come 9 to a sheet.
